# FalloutNV.pdb — reverse engineering

Типы для **Fallout: New Vegas** `FalloutNV.exe` **1.4.0.525 (GOG)**, SHA-256
`42fee7d6cd74e801372aa89c8f71c974cebd3c20ec9ad43d1465b8fa9646b49c`: классы, поля, таблицы виртуальных методов и
перечисления, взятые из утёкшего Xbox 360 PDB как подсказка и **проверенные по коду PC**. Они добавлены в PDB
сообщества xNVSE (те же 138 171 публичное имя, тот же GUID/age), поэтому отладчики, Ghidra и IDA подхватывают его
вместо исходного.

*Types for Fallout: New Vegas 1.4.0.525 (GOG): class layouts, vtables and enums hinted by the leaked Xbox 360 PDB and
verified against the PC executable, merged into the xNVSE community PDB. Documentation is in Russian.*

**Текущая версия: v0.5.3.** Что менялось — [`CHANGELOG.md`](CHANGELOG.md); подробно о версии —
[`README_RU.md`](README_RU.md).

## Где взять PDB

Прямо здесь: `FalloutNV.pdb` в корне — с v0.4.1 это **строгий** PDB (только доказанное; для хуков и плагинов),
`research/FalloutNV.pdb` — исследовательский (всё, с пометками). Положить один из них рядом с `FalloutNV.exe`.
Любая прошлая версия — в истории коммитов (коммит на версию, «vX.Y: …»). Рядом — всё, из чего PDB собран и чем
проверен: заголовки C++, доказательства по коду PC, скрипты для Ghidra/IDA, инструменты пересборки.

## Что в репозитории

| Путь | Что это |
|---|---|
| `fnv_types_v*.h`, `*.meta.json` | типы для C++ (MSVC/clang, x86) со `static_assert` и раскладки, ровно те, что в PDB |
| `FalloutNV.pdb` | готовый PDB (с v0.4.1 — строгий) |
| `research/` | (с v0.4.1) исследовательская сборка: PDB и заголовок — всё, включая непроверенное, с пометками |
| `evidence/` | доказательства: каждое обращение к полю — адрес и байты команды PC; отчёт `REPORT.md` |
| `scripts/` | привязка типов к функциям в Ghidra и IDA |
| `tools/` | пересборка PDB из заголовков и повтор всех проверок |
| `test_manifest.json` | (с v0.3.1) хэши файлов, версии инструментов, команды и ожидаемые числа |

## Правила

- Имена из Xbox PDB помечены `(Xbox PDB)` и служат подсказкой; в строгий PDB попадает только подтверждённое на PC.
- **Архив и дампы Xbox PDB сюда не кладутся и не распространяются.** Для пересборки PDB и всех проверок они не
  нужны (нужны свой `FalloutNV.exe` и PDB xNVSE); только генерации заголовков нужен свой дамп.
- Файлов игры (`FalloutNV.exe` и др.) здесь нет.
- Это исследовательский материал, не готовый ABI: перед записью в память игры из плагина — живая проверка поля.
