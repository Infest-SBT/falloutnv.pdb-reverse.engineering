# Ограничения A11

- Импорты `InterlockedIncrement/Decrement` — модели (±1 по адресу, вернуть новое значение); слоты 1 и 38 чужих
  объектов — заглушки с очисткой 0 и 4 по модели теста.
- SNaN: поведение x87 на сигнальном NaN эмулятором не воспроизводится; модель следует Intel SDM, но на настоящем CPU
  не проверено. Основные тесты — без SNaN.
- Тип аргумента не доказан (ABI — да, раскладка копируемых полей — да, класс — нет).
- Правило «копировщика» (тело копирует поля this в аргумент + именованный слот передаёт аргумент в этот слот) — не
  принятое правило; без решения Астры тождество не назначается.
- Не анализировались: вызывающие CopyTo/CopyToMembers; что делает слот 38 контроллера.
