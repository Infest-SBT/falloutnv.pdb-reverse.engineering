# Ограничения S01 / S04

- **Область — не вся программа.** Записи `+0x18` искались в функциях vtable классов семейства NiAVObject (RTTI) и в
  функциях с именами этих классов (909 функций). Запись поля из любой другой функции не исключена.
- **Классификация записей по базе.** Константа 0 считается безопасной при любой базе регистра (ноль не противоречит
  утверждению). Ненулевые записи разобраны исполнением с метками; база `edx` в UpdateParallel классифицирована
  вручную (шаг массива 0x20).
- **Вызывающие по vtable не найдены.** Поиск косвенных вызовов слотов 49/50 по смещению `[vptr+0xC4]/[vptr+0xC8]`
  без типа получателя даёт сотни совпадений у других классов — этим путём не разрешается.
- **Прямые вызовы AttachChild/SetAt**: `this` вызывающей доказан только для вызова через vtable (RTTI).
- **Эмулятор**: вызывающие исполнялись от входа до вызова; где не дошли (MagicShaderHitEffect), исполнялся линейный
  участок перед вызовом с моделями вызовов, чья очистка определена slotproof.
- **Зонд** (`runtime_probe/`) проверен только в эмуляторе (`selftest.json`): потоки, загрузчик xNVSE и память игры
  там не моделируются. Наблюдение в игре покажет классы на выполненных путях, а не отсутствие других.
